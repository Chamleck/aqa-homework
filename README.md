## Конфликт слияния

Конфликт слияния возникает когда две ветки изменяют одну и ту же строку файла
по-разному, и Git не может автоматически решить какое изменение оставить.
В данном случае конфликт возник потому что каждая feature-ветка редактировала
одни и те же строки в Program.cs, добавляя разные хобби.
Для разрешения я использовал инструмент Merge Revisions в Rider — оставил все
хобби в итоговом файле, убрав дублирующуюся строку My hobbies:.
